# 파이썬 흐름 실험실

고등학교 1학년 정보 수업용 자료입니다. 코드를 한 줄씩 실행하면서 변수, 조건, 출력이 어떻게 바뀌는지 볼 수 있어요.

첫 화면(`index.html`)에서 카드를 골라 각 실험실로 들어갑니다.

| 폴더 | 실험실 | 상태 |
|---|---|---|
| `while/` | while문 흐름 실험실 | 열림 |
| `for2/` | 이중 for문 흐름 실험실 | 준비 중 |
| `list/` | 리스트 실험실 | 준비 중 |
| `mylab/` | 내 맘대로 실험실 (직접 쓴 코드 따라가기) | 열림 |

새 실험실이 완성되면 폴더에 `index.html`을 넣고, 첫 화면 `index.html`의 `LABS` 목록에서 그 카드의 `href`를 채우면 카드가 열립니다.

## 내 맘대로 실험실
- 학생이 직접 쓴 파이썬 코드를 한 단계씩 실행하며 줄, 조건 결과, 변수, 출력을 보여 줍니다.
- 브라우저 안에서 진짜 파이썬([Pyodide](https://pyodide.org) 0.26.4, jsDelivr CDN)으로 실행합니다. 처음 열 때 몇 초 동안 불러옵니다.
- `input()` 값은 미리 적어 두거나, 비워 두면 실행할 때 물어봅니다.
- 무한 반복을 막기 위해 1500단계까지만 기록합니다.

## 관리자 모드
- 모든 실험실 오른쪽 위 **🔒 관리자** → 비밀번호 입력 (`admin.js`의 `HASH`에 SHA-256 값으로 저장)
- **수업 화면 모드:** 글자 크게 + 전체 화면 + 설명·바닥글 숨김
- **복사 막기 풀기:** 관리자 브라우저에서만 예제 코드 복사 허용
- **카드 열기/잠그기:** 카드의 열림 상태는 `labs.json`에 있어요. 관리자 패널에서 스위치를 바꾸고 「설정 복사하고 GitHub 열기」를 누른 뒤, GitHub 편집 화면에 붙여 넣고 Commit 하면 1~2분 뒤 학생 화면에 반영돼요. 잠긴 카드도 관리자는 미리 볼 수 있어요.
- 정적 사이트라서 비밀번호는 학생이 우연히 들어가는 것을 막는 정도예요. 잠긴 실험실도 주소를 직접 치면 열려요.
