# 파이썬 흐름 실험실

고등학교 1학년 정보 수업용 자료입니다. 코드를 한 줄씩 실행하면서 변수, 조건, 출력이 어떻게 바뀌는지 볼 수 있어요.

첫 화면(`index.html`)에서 카드를 골라 각 실험실로 들어갑니다.

| 폴더 | 실험실 | 상태 |
|---|---|---|
| `for1/` | for문 흐름 실험실 (for 형식 · 369 게임 · 문제 · 도전과제) | 열림 |
| `while/` | while문 흐름 실험실 | 열림 |
| `for2/` | 중첩 제어구조 흐름 실험실 | 열림 |
| `list/` | 리스트 흐름 실험실 | 열림 |
| `mylab/` | 내 맘대로 실험실 (직접 쓴 코드 따라가기) | 열림 |
| `games/` | 🎮 코드 게임랜드 (게임 4개) | 열림 |

새 실험실이 완성되면 폴더에 `index.html`을 넣고, 첫 화면 `index.html`의 `LABS` 목록에서 그 카드의 `href`를 채우면 카드가 열립니다.

## for문 흐름 실험실 (`for1/`)
프린트 (6) 「반복문 for」의 코드를 한 단계씩 실행하며 흐름을 봐요. while을 배우기 전 단계라 첫 화면 맨 앞(01)에 있어요.
- 1) for 형식: `for a in [1,2,3]`, `for a in range(1, 9)`
- 2) 예제 1-1 369 게임: 입력값(말한 숫자)을 바꿔 가며 실행, 틀리면 break
- 3) 문제 (1) 1~50 합, (2) 1~num 곱(입력 4 → 24), (3) 구구단 4단: 빈칸 정답을 위에 적고 정답 코드를 바로 실행
- 4) 도전과제 (1) 구구단 단 입력, (2) 랜덤 곱셈 게임(`import random`, 실험실에서는 매번 같은 문제), (3) 1~30 홀짝: 정답 예시 코드를 실행

## 중첩 제어구조 흐름 실험실 (`for2/`)
프린트 (8)의 「2. 중첩 제어구조」와 「문제를 풀어봅시다」를 그대로 담았어요.
- ① for 안에 if: 예제 3-1 (80점 이상인 점수의 개수)
- ② while 안에 if: 예제 3-2 (0을 입력할 때까지 짝수만 더하기, 입력 3 4 5 6 0)
- ③ for 안에 for: 예제 3-3 (별찍기), 예제 3-4 (i * j 곱셈), 예제 3-5 (a[j]를 계단처럼 출력)
- 문제를 풀어봅시다: 문제 1~4는 내 답을 모두 맞혀야 실행 화면이 열립니다.
- (도전)문제 5 🍬: 학생이 코드를 직접 입력(붙여넣기 막힘)하고 제출하면 숨은 테스트로 채점합니다. 점수 리스트를 `[50, 70, 90, 60]`, `[100, 100]`으로 바꿔도 맞아야 통과(숫자 직접 출력·`>` 사용은 실패)하고, 통과하면 「도전 성공! 마이쮸 획득」 화면이 나옵니다.
  - 정답 코드는 페이지에 그대로 두지 않고 관리자 비밀번호로 암호화했습니다. 관리자 모드에서 「🔑 정답 코드 보기 (선생님)」 → 비밀번호를 넣으면 보입니다.
  - 관리자 비밀번호를 바꾸면 정답 코드도 새 비밀번호로 다시 암호화해야 합니다.
- if / elif / else, while, 비교 연산, input(), int(), 소수(/) 계산을 지원하고 순서도에 조건(마름모)을 그립니다.

## 내 맘대로 실험실
- 학생이 직접 쓴 파이썬 코드를 한 단계씩 실행하며 줄, 조건 결과, 변수, 출력을 보여 줍니다.
- 브라우저 안에서 진짜 파이썬([Pyodide](https://pyodide.org) 0.26.4, jsDelivr CDN)으로 실행합니다. 처음 열 때 몇 초 동안 불러옵니다.
- `input()` 값은 미리 적어 두거나, 비워 두면 실행할 때 물어봅니다.
- 무한 반복을 막기 위해 1500단계까지만 기록합니다.

## 관리자 모드
- 모든 실험실 오른쪽 위 **🔒 관리자** → 비밀번호 입력 (`admin.js`의 `HASH`에 SHA-256 값으로 저장)
- **수업 화면 모드:** 글자 크게 + 전체 화면 + 설명·바닥글 숨김
- **복사 막기 풀기:** 관리자 브라우저에서만 예제 코드 복사 허용
- **카드 열기/잠그기:** 카드의 열림 상태는 `labs.json`에 있어요. 관리자 패널에서 스위치를 바꾸고 「설정 복사하고 GitHub 열기」를 누른 뒤, GitHub 편집 화면에 붙여 넣고 Commit 하면 1~2분 뒤 학생 화면에 반영돼요. 잠긴 카드도 관리자는 미리 볼 수 있어요.
- 정적 사이트라서 비밀번호는 학생이 우연히 들어가는 것을 막는 정도예요. 잠긴 실험실도 주소를 직접 치면 열려요.

## 🎮 코드 게임랜드
빈칸을 채워 코드를 완성하고 ▶ 실행을 누르면 캐릭터가 코드대로 움직여요. 한 번에 성공하면 별 3개, 진행 상황은 브라우저에 저장돼요.
- 🐱 **고양이 길찾기** (while · 조건 · break, 4레벨): while 조건, 모퉁이에서 if로 돌기, while True + break, 생선 세기(count += 1)
- 🌸 **꽃밭 심기** (이중 for, 4레벨): range로 네모·가운데 꽃밭, 계단(range(i + 1)), 대각선(if 조건)
- 🍩 **도넛 가게** (리스트, 4레벨): 인덱스, -1, append, for + if로 도넛만 담기
- 🐣 **몇 번 돌까? 퀴즈** (흐름 읽기, 10문제): 결과를 맞히면 병아리가 자라고, 틀리면 실행 흐름을 한 줄씩 보여 줘요

## 📄 학습지 자료실 (`materials/`)
첫 화면 위쪽 **📄 학습지** 버튼으로 들어가요 (카드 아님). 학습지마다 👀 바로 보기 · ↗ 새 창 · ⬇ 내려받기 · 🧪 실험실 바로 가기가 있어요.

**새 학습지 올리는 법 (GitHub 웹에서)**
1. 저장소에서 `materials` 폴더 → **Add file → Upload files** → PDF를 끌어다 놓고 **Commit changes**. 파일 이름은 한글도 돼요 (예: `(7)반복문 while.pdf`). 같은 이름으로 올리면 새 파일로 바뀌어요.
2. `materials/list.json`을 열고 ✏️ 연필 → 아래 형식으로 한 덩어리를 추가하고 Commit.
```json
  {
    "file": "(7)반복문 while.pdf",
    "no": "(7)",
    "title": "반복문 while",
    "unit": "Ⅲ. 알고리즘과 프로그래밍",
    "desc": "while 형식, break · continue, 숫자 맞추기 게임",
    "lab": "../while/index.html"
  }
```
   덩어리 사이에는 쉼표(,)를 넣어요. `lab`은 연결할 실험실 주소이고, 없으면 그 줄을 빼도 돼요.

## 오늘 방문자 수 (today)
첫 화면 오른쪽 위에 `today: N`이 작게 나와요. 무료 방문자 통계 [GoatCounter](https://www.goatcounter.com)를 써요.
- **켜는 법:** GoatCounter에 가입해 Code(예: `dayoung-pylab`)를 정하고, Settings에서 "Allow adding visitor counts on your website"를 켠 뒤, `index.html`의 `const GC_CODE='...';`에 Code를 넣어요 (지금: `dayoung` → https://dayoung.goatcounter.com). 비어 있으면 숫자를 숨겨요.
- 같은 브라우저는 하루에 한 번만 세요(새로고침해도 안 늘어남). 첫 화면을 연 사람만 세요.
- GoatCounter 하루는 세계 표준시(UTC) 기준이라 한국 시간 오전 9시에 0부터 다시 세요. 숫자는 몇 시간 늦게 반영될 수 있어요.
- GoatCounter 사이트(`https://코드.goatcounter.com`)에 로그인하면 날짜별 방문 그래프도 볼 수 있어요.
- 카운터 서비스에 접속할 수 없으면 숫자만 안 보이고 사이트는 그대로 동작해요.
