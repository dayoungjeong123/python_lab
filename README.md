# 파이썬 흐름 실험실

고등학교 1학년 정보 수업용 자료입니다. 코드를 한 줄씩 실행하면서 변수, 조건, 출력이 어떻게 바뀌는지 볼 수 있어요.

첫 화면(`index.html`)에서 카드를 골라 각 실험실로 들어갑니다.

| 폴더 | 실험실 | 상태 |
|---|---|---|
| `while/` | while문 흐름 실험실 | 열림 |
| `for2/` | 이중 for문 흐름 실험실 | 열림 |
| `list/` | 리스트 흐름 실험실 | 열림 |
| `mylab/` | 내 맘대로 실험실 (직접 쓴 코드 따라가기) | 열림 |
| `games/` | 🎮 코드 게임랜드 (게임 4개) | 열림 |

새 실험실이 완성되면 폴더에 `index.html`을 넣고, 첫 화면 `index.html`의 `LABS` 목록에서 그 카드의 `href`를 채우면 카드가 열립니다.

## while문 흐름 실험실
- 1) while 형식: 예제 1-1
- 2) for → while: 변환 ①(1~19 출력), 변환 ②(구구단)
- 3) break · continue: 예제 1-2, 1-3
- 4) 숫자 맞추기 게임: 예제 1-4

## 리스트 흐름 실험실
- 1) 리스트 기본: 예제 1-1 (만들기 · 꺼내기 · 바꾸기)
- 2) 활용 3총사: 예제 1-2 (len, append, 슬라이싱)
- 3) 리스트 + for: 예제 1-3 ① 값으로 더하기, ② 인덱스로 더하기
- 리스트를 칸으로 그리고, 꺼낸 칸 · 바꾼 칸 · 추가한 칸을 색으로 표시합니다.

## 이중 for문 흐름 실험실
- 1) 이중 for 순서: 예제 2-1, 2-2(별찍기)
- 2) 들여쓰기 = 상자: 예제 2-3
- 3) 들여쓰기 실험: print 줄을 0 · 4 · 8칸으로 옮기며 실행 횟수 비교, 미션 5개
- 4) 리스트 + 이중 for: 예제 2-4
- 5) 문제 확인: 문제 1, 2, 3, 5, 6과 도전과제. 내 답을 모두 맞혀야 실행 화면이 열립니다.

## 내 맘대로 실험실
- 학생이 직접 쓴 파이썬 코드를 한 단계씩 실행하며 줄, 조건 결과, 변수, 출력을 보여 줍니다.
- 브라우저 안에서 진짜 파이썬([Pyodide](https://pyodide.org) 0.26.4, jsDelivr CDN)으로 실행합니다. 처음 열 때 몇 초 동안 불러옵니다.
- `input()` 값은 미리 적어 두거나, 비워 두면 실행할 때 물어봅니다.
- 무한 반복을 막기 위해 1500단계까지만 기록합니다.

## 관리자 모드
- 모든 실험실 오른쪽 위 **🔒 관리자** → 비밀번호 입력 (`admin.js`의 `HASH`에 SHA-256 값으로 저장)
- **수업 화면 모드:** 글자 크게 + 전체 화면 + 설명·바닥글 숨김
- **복사 막기 풀기:** 관리자 브라우저에서만 예제 코드 복사 허용
- **카드 열기/잠그기:** 카드의 열림 상태는 `labs.json`에 있어요. 관리자 패널에서 스위치를 바꾸고 「설정 복사하고 GitHub 열기」를 누른 뒤, GitHub 편집 화면에 붙여 넣고 Commit 하면 1~2분 뒤 학생 화면에 반영돼요. 잠긴 카드도 관리자는 미리 볼 수 있어요.
- 정적 사이트라서 비밀번호는 학생이 우연히 들어가는 것을 막는 정도예요. 잠긴 실험실도 주소를 직접 치면 열려요.

## 🎮 코드 게임랜드
빈칸을 채워 코드를 완성하고 ▶ 실행을 누르면 캐릭터가 코드대로 움직여요. 한 번에 성공하면 별 3개, 진행 상황은 브라우저에 저장돼요.
- 🐱 **고양이 길찾기** (while · 조건 · break, 4레벨): while 조건, 모퉁이에서 if로 돌기, while True + break, 생선 세기(count += 1)
- 🌸 **꽃밭 심기** (이중 for, 5레벨): range로 네모·가운데 꽃밭, 계단(range(i + 1)), 체크무늬·대각선(if 조건)
- 🍩 **도넛 가게** (리스트, 5레벨): 인덱스, -1, append, remove, for + if로 도넛만 담기
- 🐣 **몇 번 돌까? 퀴즈** (흐름 읽기, 10문제): 결과를 맞히면 병아리가 자라고, 틀리면 실행 흐름을 한 줄씩 보여 줘요
